# VocabBD — 130 Days Vocabulary Website

A static website built from the supplied `vocabulary 130.zip` collection.

## Features
- 130 day navigation
- Searchable word index
- Part-of-speech labels
- Original PDF reader for every day
- Responsive mobile layout
- Dark/light mode
- No backend required

## Run
Open `index.html` in a browser, or upload the whole folder to GitHub Pages / Cloudflare Pages / Netlify.

Keep the `pdfs` folder beside `index.html` and `data.js`.
